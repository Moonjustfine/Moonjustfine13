# Cosmic V58 Android-only UI update

- Real horizontal employee tabs are visible on Android.
- The secondary bottom popup menu is hidden because the top tabs expose all sections.
- Nested card styling inside the attendance metrics is removed.
- Text-only areas do not receive card backgrounds.
- Glass blur/backdrop-filter is disabled for the Android Cosmic shell.
- Sun theme uses a warmer opaque surface and no blur for sharper text.
- Web/PWA remains unchanged because new selectors are scoped to `.pt-cosmic-shell`, which is used only by the Android-only portal.
